    pto-as 后端 Pass¶

    本文档介绍 pto-as 的核心后端 Pass，它们负责将 PTO-ISA MLIR 转换为可编译的 C++ 代码。

    Pass 流水线概览¶

    ┌─────────────────────────────────────────────────────────────────────────┐
│                        pto-as Pass 流水线                                │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  PTO-ISA MLIR (Level 1/2)                                              │
│         │                                                               │
│         ▼                                                               │
│  ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐    │
│  │ InferPTOLayout  │───▶│ InferPTOMemScope │───▶│ PTOConvertToDPS │    │
│  │ (布局推断)       │    │ (内存域推断)     │    │ (SSA → DPS)     │    │
│  └─────────────────┘    └─────────────────┘    └─────────────────┘    │
│         │                                                               │
│         ▼                                                               │
│  ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐    │
│  │ PTOPlanMemory   │───▶│ InsertSync      │───▶│ PTOToEmitC      │    │
│  │ (内存规划)       │    │ (同步插入)       │    │ (代码生成)      │    │
│  └─────────────────┘    └─────────────────┘    └─────────────────┘    │
│         │                                                               │
│         ▼                                                               │
│  C++ 代码 (调用 pto-isa 虚拟指令)                                       │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

    核心 Pass 详解¶

    1. InferPTOLayout¶

    文件: lib/PTO/Transforms/InferPTOLayout.cpp

    功能: 推断 tile 数据的物理布局。

    布局类型:

    布局 助记符 说明
    ND nd 行主序 (Normal-Dimension)
    DN dn 列主序 (Dimension-Normal)
    NZ nz 分形/块布局

    为什么需要布局推断:

    • Ascend NPU 的 Cube 单元对矩阵布局有特定要求
    • NZ (分形) 布局可以提高矩阵乘法的内存访问效率
    • 不同的操作可能需要不同的输入布局

    2. InferPTOMemScope¶

    文件: lib/PTO/Transforms/InferPTOMemScope.cpp, InferPTOMemScope.h

    功能: 推断 tile buffer 应该放在哪个内存域。

    内存域:

    域 位置 用途
    vec UB Vector 运算
    mat L1 Matrix 中间数据
    left L0A Cube 左矩阵输入
    right L0B Cube 右矩阵输入
    acc L0C Cube 累加器

    推断规则:

    • tmatmul 输入 → left/right
    • tmatmul 输出 → acc
    • tadd, tmul 等向量操作 → vec
    • tload/tstore 可配置

    3. PTOConvertToDPS¶

    文件: lib/PTO/Transforms/ConvertToPTOOp.cpp

    功能: 将 SSA 形式的 tile 转换为目标传递风格 (DPS, Destination-Passing Style)。

    转换前后对比:

    // SSA 形式 (Level-1)
%result = pto.tadd %a, %b : !pto.tile<...>

// DPS 形式 (Level-2)
%buf = pto.alloc_tile : !pto.tile_buf<...>
pto.tadd ins(%a, %b : ...) outs(%buf : ...)

    为什么需要 DPS:

    • 显式管理 buffer 生命周期
    • 支持 buffer 复用优化
    • 便于后续内存规划

    4. PTOPlanMemory¶

    文件: lib/PTO/Transforms/PTOPlanMemory.cpp, PTOPlanMemory.h

    功能: 为 buffer 分配物理地址偏移。

    内存规划策略:

    1. 生命周期分析: 确定 buffer 的活跃范围
    2. 冲突图构建: 识别哪些 buffer 可以共享内存
    3. 地址分配: 为每个 buffer 分配偏移量

    示例:

    Buffer A: [0, 100)   活跃: t0 - t5
Buffer B: [0, 200)   活跃: t6 - t10   ← 可以复用 A 的内存
Buffer C: [100, 300) 活跃: t3 - t8    ← 与 A 冲突，需要不同地址

    5. InsertSync¶

    文件: lib/PTO/Transforms/InsertSync/

    功能: 插入流水线同步指令。

    同步原语:

    操作 说明
    record_event 记录流水线事件完成点
    wait_event 等待指定事件完成
    set_flag 设置同步标志
    wait_flag 等待同步标志
    pipe_barrier 全屏障

    流水线同步示例:

    时间 ──────────────────────────────────────────────────────────────▶

PIPE_MTE2:  ═══TLOAD══════════════════════════════════════════════
                 │ record_event(EVENT_ID0)
PIPE_MTE1:  ─────wait_event(EVENT_ID0)═══TMOV══════════════════════
                                           │ record_event(EVENT_ID1)
PIPE_M:     ───────────────────────────────wait_event(EVENT_ID1)═══TMATMUL═══

    相关 Pass:

    • LoweringSyncToPipe: 将高层同步转换为流水线同步
    • PTORemoveRedundantBarrier: 移除冗余屏障

    6. PTOToEmitC¶

    文件: lib/PTO/Transforms/PTOToEmitC.cpp

    功能: 将 PTO IR 转换为 C++ 代码。

    转换规则:

    PTO IR 生成的 C++
    pto.tload pto::TLOAD_TILE_IMPL(...)
    pto.tmov pto::TMOV_TILE_IMPL(...)
    pto.tmatmul pto::TMATMUL_TILE_IMPL(...)
    pto.tstore pto::TSTORE_TILE_IMPL(...)

    生成示例:

    // 输入 MLIR
%tile = pto.alloc_tile : !pto.tile_buf<loc=vec, dtype=f16, ...>
pto.tload ins(%view : !pto.partition_tensor_view<16x16xf16>)
          outs(%tile : !pto.tile_buf<...>)

    // 输出 C++
pto::Tile<f16, 16, 16> tile;
pto::TLOAD_TILE_IMPL(tile, view);

    辅助 Pass¶

    OptMemPlanForPipeline¶

    文件: lib/PTO/Transforms/OptMemPlanForPipeline.cpp

    功能: 针对流水线优化的内存规划。

    AllocToPointerCast¶

    文件: lib/PTO/Transforms/AllocToPointerCast.cpp

    功能: 将 allocation 转换为指针转换。

    PTOViewToMemref¶

    文件: lib/PTO/Transforms/PTOViewToMemref.cpp

    功能: 将 PTO view 操作转换为 MLIR memref。

    PTOWrapFunctionsInSections¶

    文件: lib/PTO/Transforms/PTOWrapFunctionsInSectionsPass.cpp

    功能: 将函数包装在特定的 section 中。

    PTOVerifyTFree¶

    文件: lib/PTO/Transforms/PTOVerifyTFreePass.cpp

    功能: 验证 tile buffer 的释放正确性。

    PTOResolveReservedBuffers¶

    文件: lib/PTO/Transforms/PTOResolveReservedBuffersPass.cpp

    功能: 解析保留 buffer 的实际地址。

    Pass 调用顺序¶

    # 查看 ptoas 调用的 Pass 顺序
ptoas input.pto --print-ir-after-all -o output.cpp

    典型的 Pass 顺序:

    1. InferPTOLayout
    2. InferPTOMemScope
    3. PTOConvertToDPS
    4. PTOPlanMemory
    5. InsertSync / LoweringSyncToPipe
    6. PTORemoveRedundantBarrier
    7. PTOToEmitC

    调试技巧¶

    # 打印每个 Pass 后的 IR
ptoas input.pto --print-ir-after-all -o output.cpp

# 只打印特定 Pass 后的 IR
ptoas input.pto --print-ir-after=PTOPlanMemory -o output.cpp

# 保留中间文件
ptoas input.pto --save-temps -o output.cpp
